# MAROON

_MAROON_ --- это веб-приложение интернет-магазина цветов, предназначенное
для просмотра и покупки цветочных композиций, букетов и домашних
растений. Проект предоставляет пользователям возможность ознакомиться с
ассортиментом, изучить информацию и выбрать подходящий товар.

## Основной функционал

- Просмотр каталога цветочных композиций, букетов и домашних растений.
- Сортировка товаров.
- Добавление товаров в корзину.
